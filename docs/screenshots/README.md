# 截图说明

把以下 3 张截图放到本目录，文件名要对得上（根 `README.md` 的「界面预览」直接引用）：

| 文件名 | 拍什么 | 要点 |
|---|---|---|
| `ask.png` | 提问资料内问题 + 回答 | **展开「引用来源」**，让命中片段、章节、相关度可见——这是“可溯源”的卖点 |
| `refuse.png` | 提问与资料无关的问题 | 展示“资料中未检索到足够依据”的拒答提示 + 最接近片段——这是“降幻觉”的卖点 |
| `docs.png` | 「设置与资料」→「资料管理」标签 | 资料列表（文件名、chunk 数、大小、替换/删除），体现知识库管理能力 |

## 拍摄建议

- 浏览器窗口别太宽（约 1100–1300px），截出来在 README 表格里更清晰。
- 用样例资料就行（内置那份毕业论文），不必换。
- 深色/浅色主题都可，三张保持一致。
- 截 PNG；单张控制在 ~500KB 内，避免仓库膨胀。
